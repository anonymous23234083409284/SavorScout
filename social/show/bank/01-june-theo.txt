# THE SCRIPT BANK, file 1: June and Theo, roommates, outside on the quad.
#
# June says unhinged things in a normal voice. Theo has a system for everything and none work.
# The game of every scene: Theo is proud, June is done, nobody learns.
#
# HOW A SCRIPT IS WRITTEN (python social/pipeline/show.py bank list | lint | make <id> [campus]):
#   == id | format | cast (left,right) | set | title on the first shot | TikTok caption
#   J deadpan > A line.            who (M Milo, S Scout, J June, T Theo, N narrator), then optional
#                                  face (neutral panic shock deadpan smug happy sad squint plead determined),
#                                  pose (idle headgrab armsup point shrug phone paper chin facepalm present),
#                                  2 (both in frame), shake, cam (looks at us), hold=0.6 (pause after)
#   *stars* colour a caption word. A word in CAPITALS is shouted (ElevenLabs) and coloured.
#   [deadpan] at the end of a line is the ElevenLabs acting tag. Use it only where the delivery
#   is the joke: every tag costs characters.
#   ! J deadpan 1.2                a silent stare (every script needs one pause: this or hold=0.5+)
#   MAP w S > There are {w} ...    the real map and number for whatever campus the episode is made for
#   MEME cat falling | TEXT ABOVE | N > line     a meme with the narrator over it (file 3)
# The last spoken line gets the site's name on screen automatically; it must say "Savor Scout".
# Rules: first line 9 words or fewer, no line over 16, 35-70 words is the sweet spot (cheap to voice).
